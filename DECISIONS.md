# Decisions

Choices made where the spec was silent or contradicted itself. Each one is the simplest option that kept work moving; anything marked **(Q#)** is also on the open-questions list in `QUESTIONS.md`.

| ID | Decision | Why |
| --- | --- | --- |
| D-001 | No MUD code is compiled or copied. Formulas are re-typed from reading the C; every ported ability carries `source` (`file.c:function`). All log text is original (`game/core/combat_text.gd`). | Spec license note. |
| D-002 | Class indices come from `Data/class_db.json` order (mage=0, cleric=1, thief=2, warrior=3 … knifer=16). Tier 2 = +18, tier 3 = +36 gives warrior→gladiator→knight, thief→mercenary→blade, mage→wizard→sorcerer, knifer→tumbler→wardancer. | Matches the spec's examples. `Documents/DS_SCHEMA_DELTAS.md`'s "canonical" table disagrees (it lists thief=4, mage=5) and is wrong for this file. |
| D-003 | Player-facing class names use the MUD's tier names (Warrior/Gladiator/Knight etc.) because they're generic fantasy terms. | Spec "keep generic fantasy names". |
| D-004 | `import_mud_data.py` reads weapon numbers from `Game/Resurrected/data/area/*.are`, not `Data/weapon_db.json` / `Data/equip_db.json`. **(Q11)** | Those JSON files have no usable stats: `weapon_db.json` has 5 placeholder weapons, all `0d0`; `equip_db.json` has values `[]` and mis-parsed types. The area files hold real `#OBJECTS` stat lines. Only numbers are imported (median min/max by weapon type and run-level band); MUD item names are not. |
| D-005 | Weapons use the MUD's `value[1]`/`value[2]` directly as min/max (that's what `get_char_min/max` read), not as dice. | Faithful to `fight.c`. |
| D-006 | Cooldown in rounds = `ceil(beats / 4)`, min 1 (bash 3, kick 3, backstab 5, circle/charge 6, magic fist 1). Tunable as `balance.cooldown_divisor`. **(Q4)** | Spec says "beats becomes its cooldown in rounds". Read literally, bash would be 10 rounds and circle 24 — most abilities would fire once per fight. Beats are pulses; 4 pulses = 1 second, and playback is 1 round per second, so beats/4 ≈ the MUD lockout in seconds. |
| D-007 | Cooldown classes (Warrior, Thief, Knifer) pay no mana. In the MUD berserk costs 75 mana, warcry 70, storm of blades 150. **(Q12)** | Spec table: their resource is "Cooldowns". |
| D-008 | Weapon skill (sword, dagger…) is 75% at level 1, +2/level, cap 95. Ability/passive proficiency follows the spec (40% +10/level, cap 95). **(Q14)** | `get_char_min/max` multiply all weapon damage by weapon skill; at 40% every early swing would do 40% damage. |
| D-009 | MUD "level" inside ported formulas = in-run level × 10 (`balance.level_scale`). | Keeps the C formulas (bash `level/2..level`, `dice(level,16)`) intact. |
| D-010 | The spec's "starting actives" unlock at in-run level 1 even when the MUD gates them later (kick: warrior 12 → L2; whirlwind: knifer 37 → L4). Everything else unlocks at `ceil(MUD level / 10)` for the current tier. **(Q5)** | Spec table lists them as starting actives. |
| D-011 | "stun" is a passive that powers bash's stun rider (warrior line uses skill/2, others skill/4, as in `do_shield_smash`). The rebuilt `do_bash` only prints the stun message without setting `stunned`; we set 1d2 rounds. **(Q6)** | There is no `do_stun`; `skill_db` stun has beats 0 and no command. |
| D-012 | MUD buff durations are in ticks (~30s+). Overrides set round durations: berserk 6, warcry 10, armor/shield 12, sanctuary 6, haste 8, slow 4, sleep 2. Armor/shield spells use AC −400 (the MUD's −20 is meaningless at our scale). | Ticks don't map to a 10–20 round fight. |
| D-013 | Non-telegraphed enemy hits are capped at 35% of the player's max HP inside `damage()`. Telegraphed attacks deal `hp_pct` of the player's max HP. A test also checks every monster ability's max against the weakest level-1 player. | Spec "no unanswerable one-shots" guaranteed by construction. |
| D-014 | Telegraph answers. Interrupt: target stunned, knocked down (bash/trip), dazed, asleep or transfixed before it lands. Brace: shield + shield block, Cobra stance, or armor/shield/sanctuary buff → damage × 0.35. Evade: Mist stance or the attacker is blind → miss. Outlast: lands as a 3-round bleed (heal, sanctuary, potion or kill first). | Spec table; multipliers are guesses in `balance.json`. |
| D-015 | Sleep answers Interrupt and Evade (it cancels the wind-up). Burst openers (backstab, circle, charge, cross slash, storm of blades) count as Outlast answers. Warrior kit adds dirt kicking (MUD L4) and trip (MUD L40) so the line can Evade. **(Q7, Q9)** | Needed for the spec's coverage rule; spec kits alone don't cover every tag. |
| D-016 | Damage wakes a sleeping target. | Standard design; ROM behaviour here is position-based and doesn't map cleanly. |
| D-017 | Defenses (parry/dodge/block) only apply to normal swings, not to backstab/circle/kick etc. Everyone gets the 10% floor on parry (if armed) and dodge, even at 0 skill. | Faithful to `one_hit()` (defenses only when `dt >= TYPE_HIT`) and the `URANGE(10, …)` clamps. |
| D-018 | Vulnerable = +25% damage, not +50%. | Spec said "+50% (verify)"; `damage()` does `dam += dam/4`. |
| D-019 | Spell damage is multiplied by `balance.spell_damage_scale` (0.2), after the MUD's own −25% spell penalty. **(Q15)** | Magic fist is 50–145 at MUD level 10; a level-1 sword swing is ~7–15. |
| D-020 | Player acts first in a round (rules → queued tap), then enemies (telegraphs resolve, then their rules), then auto-attacks: player, then each enemy. Using an ability doesn't cost the auto-attack round. | Spec round order; MUD skills run alongside `multi_hit`. |
| D-021 | Player always targets the first living enemy; "enemy is telegraphing / has status / HP below" rules retarget to the matching enemy. | Simplest. |
| D-022 | 2nd/3rd dual (off-hand extra attacks), offhand skill, ironskin, two-handed fumble and the gang-up modifiers are left out of v1. Fifth attack isn't in any v1 kit. | Not in the spec's kits; keeps the sim small. |
| D-023 | RNG is our own Park–Miller generator (`game/core/rng.gd`), not Godot's. | Bit-identical on every platform and Godot version; trivially serializable for save/resume. |
| D-024 | Dance is one ability with an argument: rules say `dance:mist`, `dance:storm`, `dance:cobra`, `dance:predator`. Active stance shows as a status `stance_<name>` so "I don't have buff" works on it. Dance-of-the-devil is left out. | One rule slot per stance switch; no new condition type. |
| D-025 | Chain lightning is ported in full: sweeps all enemies round-robin, −8 levels per hit, and arcs back into the caster for `dice(level,10)` when only one target remains. | Faithful to `spell_chain_lightning`. Worth knowing — it hurts solo-target mages. |
| D-026 | Hand-authored data lives beside the import: `monsters.json`, `balance.json` (and later `boons.json`, `rooms.json`). The importer only writes `classes.json`, `abilities.json`, `items.json`. Tuning goes in `overrides/<file>.json`, deep-merged at load. | Spec rule 4. |
